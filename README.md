**Course Code:** CSE 413

## Overview

This repository contains my submission for the Day 1 lab assignment of the Simulation and Modeling course. The notebook covers scalar/array operations, matrix operations, and vector functions using **NumPy**, along with a bonus data visualization using **Seaborn**.

## File

- `SIM_Lab1_Monika_Akter_1047.ipynb` — main Jupyter/Colab notebook with all tasks completed and outputs shown.

## Tasks Completed

1. **Scalar & Array Operations**
   Applied `scalar = 3.7` and a custom 6-element array through trigonometric (`sin`, `cos`, `tan`, `arcsin`, `arccos`, `arctan`), exponential, logarithmic, absolute value, square root, remainder, and rounding (`round`, `floor`, `ceil`) functions.

2. **3×2 Matrix Operations**
   Repeated the same set of operations demonstrated in class on a 2×2 matrix, applied instead to a custom 3×2 matrix, with input clipping to avoid `arcsin`/`arccos` domain errors.

3. **Vector Functions on a 2×3 Matrix**
   Computed max/min values with their indices, matrix length, row-wise descending sort, entire-matrix descending sort (via `.flatten()`), sum, product, median, mean, and standard deviation on a 2×3 float matrix.

4. **Bonus**
   Visualized a matrix using `seaborn.heatmap()` and generated random matrix values with `np.random.uniform()`.
